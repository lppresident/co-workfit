## 🔩 쇠 (Iron) 시스템

### 강도 계수 (심박수 기반)

| 강도 | 심박수 | 계수 |
|------|--------|------|
| 저강도 | < 100 bpm | 0.5 |
| 중강도 | 100-130 bpm | 0.83 |
| 고강도 | 130-150 bpm | 1.0 |
| 매우 고강도 | 150+ bpm | 1.3 |

### 점수 계산

```
헬스 점수 = 운동 시간(분) × 강도 계수
예: 60분 × 0.83(중강도) = 50점
```

## 🔄 정산 로직

### 일일 정산 프로세스

1. 앱 실행 시 `CheckPendingSettlements` 이벤트 발생
2. 정산 필요 여부 확인 (마지막 정산일 체크)
3. 종료된 챌린지 조회
4. 각 챌린지별 보상 계산
5. 최고 보상 챌린지 선택 (통나무/쇠 각각)
6. 개인 운동 보상 처리 (챌린지 보상 없을 경우)
7. 재화 지급 및 정산 기록 저장
8. 오래된 정산 기록 삭제 (7일 초과)

### Firestore 구조

```
users/{userId}/
├── woodAmount: int           # 현재 통나무
├── woodLifetimeEarned: int   # 누적 통나무
├── ironAmount: int           # 현재 쇠
├── ironLifetimeEarned: int   # 누적 쇠
├── lastWoodSettlementDate: timestamp
├── equippedItems: {
│   head: "item_id" | null,
│   body: "item_id" | null,
│   legs: "item_id" | null
│ }
├── inventory/{itemId}/
│   ├── quantity: int
│   └── updatedAt: timestamp
└── wood_settlements/{date}/
    ├── totalWoodAwarded: int
    ├── totalIronAwarded: int
    ├── selectedChallengeId: string
    ├── challengeRewards: [...]
    └── settlementDate: timestamp
```
