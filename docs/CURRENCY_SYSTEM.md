# 재화 및 제작 시스템

> Co-WorkFit의 통나무/쇠/흙 재화 시스템 및 아이템 제작 가이드

---

## 📊 재화 개요

| 재화 | 이모지 | 획득 방법 | 용도 |
|------|--------|----------|------|
| **통나무 (Wood)** | 🪵 | 달리기 챌린지 | 달리기 장비 제작 |
| **쇠 (Iron)** | 🔩 | 헬스 챌린지 | 헬스 장비 제작 |
| **흙 (Soil)** | 🌱 | 명상/요가 챌린지 | 명상 장비 제작 |

## 🪵 통나무 (Wood) 시스템

### 보상 구조

#### 개인 운동 보상
| 항목 | 보상 |
|------|------|
| 기본 보상 | 5 통나무 |
| 거리당 | +2 통나무/km |
| 일일 첫 운동 보너스 | +3 통나무 |

#### 챌린지 기여 보상
| 항목 | 보상 |
|------|------|
| 기여 거리당 | +1 통나무/km |
| 첫 기여 보너스 | +5 통나무 |

#### 챌린지 성공 보상 (성공 시)
| 항목 | 보상 |
|------|------|
| 완료 보너스 | +30 통나무 |
| MVP 보너스 (1위) | +20 통나무 |
| 협력 보너스 | +3 통나무/참가자 (최대 30) |

#### 마일스톤 보너스
| 거리 | 보상 |
|------|------|
| 10km 이상 | +10 통나무 |
| 하프마라톤 (21km) | +30 통나무 |
| 풀마라톤 (42km) | +50 통나무 |

## 🔩 쇠 (Iron) 시스템

### 강도 계수 (심박수 기반)

| 강도 | 심박수 | 계수 |
|------|--------|------|
| 저강도 | < 100 bpm | 0.5 |
| 중강도 | 100-130 bpm | 0.83 |
| 고강도 | 130-150 bpm | 1.0 |
| 매우 고강도 | 150+ bpm | 1.3 |

### 점수 계산

```
헬스 점수 = 운동 시간(분) × 강도 계수
예: 60분 × 0.83(중강도) = 50점
```

## 📁 코드 구조

### 재화 시스템

```
lib/features/
├── wood/
│   ├── domain/entities/wood_reward_constants.dart
│   └── ...
├── iron/
│   └── domain/entities/iron_reward_constants.dart
├── soil/
│   └── domain/entities/soil_reward_constants.dart
└── currency/
    └── presentation/widgets/  # 공통 재화 UI
```

### 제작 시스템

```
lib/features/craft/
├── domain/
│   ├── entities/
│   │   ├── item_entity.dart
│   │   ├── item_recipes.dart      # 아이템 레시피 (30종)
│   │   └── character_sprite.dart  # 스프라이트 정의
│   └── ...
└── presentation/
    └── widgets/
        └── character_painter.dart  # 픽셀아트 렌더링
```

## 🗄️ Firestore 구조

```
users/{userId}/
├── woodAmount: int           # 현재 통나무
├── woodLifetimeEarned: int   # 누적 통나무
├── ironAmount: int           # 현재 쇠
├── ironLifetimeEarned: int   # 누적 쇠
├── soilAmount: int           # 현재 흙
├── soilLifetimeEarned: int   # 누적 흙
├── equippedItems: {
│   head: "item_id" | null,
│   body: "item_id" | null,
│   legs: "item_id" | null
│ }
└── inventory/{itemId}/
    ├── quantity: int
    └── updatedAt: timestamp
```
